# AI-Powered Personalized Diet and Workout Planner

An ML-based fitness recommendation system that provides personalized exercise, equipment, and diet recommendations based on an individual's body details and health conditions.

## Problem Statement

Most people do not know which exercises, equipment, or diet plans are suitable for their body type and health conditions. Generic fitness plans often ignore important factors such as BMI, hypertension, and diabetes. Hiring a personal trainer or dietitian can also be expensive and inaccessible for many people.

## Objective

To develop a machine learning-based system that uses personal and health-related information to generate personalized fitness recommendations, including:

- Suitable exercise routines
- Required fitness equipment
- Personalized diet plans

## Key Features

- **Personalized Recommendations:** Provides recommendations based on user details and health conditions.
- **BMI-Based Analysis:** Uses height and weight to calculate BMI.
- **Health-Aware Suggestions:** Considers conditions such as hypertension and diabetes.
- **Exercise Recommendations:** Suggests suitable exercises.
- **Equipment Recommendations:** Identifies the equipment needed for recommended exercises.
- **Diet Recommendations:** Provides diet suggestions based on user information.
- **User-Friendly Interface:** Offers a simple interface for entering details and viewing results.

## Input Features

The system uses personal and health-related information such as:

- Sex
- Age
- Height
- Weight
- BMI
- Hypertension
- Diabetes

## Recommendations Generated

The system provides three main types of recommendations:

1. Exercise routine
2. Fitness equipment
3. Diet plan

## Technologies Used

- **Programming Language:** Python
- **Data Analysis:** Pandas, NumPy
- **Machine Learning:** Scikit-learn
- **Application Interface:** Streamlit

## Project Workflow

1. Dataset Collection
2. Data Understanding and Exploratory Data Analysis (EDA)
3. Data Cleaning and Preprocessing
4. Feature Selection and Preparation
5. Model Training and Evaluation
6. Recommendation Generation
7. Application Development using Streamlit

## Future Improvements

- Add food preference options such as vegetarian and non-vegetarian.
- Include activity levels and daily calorie requirements.
- Expand the recommendation dataset.
- Improve recommendation quality with additional user information.
- Add user profiles and recommendation history.

## Scope and Disclaimer

This project is developed for educational and general health-awareness purposes. It aims to help users explore personalized fitness recommendations and develop healthier habits.

The recommendations are not a substitute for professional medical advice, diagnosis, or treatment. Users with existing health conditions should consult qualified healthcare professionals before making changes to their diet or exercise routine.
